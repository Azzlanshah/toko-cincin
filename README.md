# The Core - Toko Cincin

<img src="https://github.com/user-attachments/assets/7fb9926f-3db6-4dea-9396-c079488c4c18" alt="Screenshot The Core" width="600" />

Proyek website *landing page* statis untuk toko perhiasan cincin bernama **The Core**. Proyek ini merupakan arsip tugas praktik dari **kelas 11** yang dibuat untuk memperkuat dasar-dasar pengembangan web *front-end* (HTML, CSS, dan interaksi JavaScript dasar).

### 🔗 Live Demo

Website ini sudah di-*deploy* dan dapat diakses secara langsung melalui GitHub Pages:

👉 **[https://azzlanshah.github.io/toko-cincin/](https://azzlanshah.github.io/toko-cincin/)**

---

## ✨ Fitur

- **Navigasi:** Menu Home dan Daftar Produk.
- **Hero Section:** Menampilkan sambutan utama dan informasi promo diskon hari Jumat.
- **Daftar Produk:** Bagian untuk menampilkan katalog cincin.
- **Tombol Melayang (Floating Button):** Tombol "Chat Sekarang" di pojok kanan bawah untuk memudahkan interaksi.

---

## 🛠️ Teknologi

- **HTML5** (Struktur halaman)
- **CSS3** (Styling dan responsivitas)
- **JavaScript** (Interaksi dasar UI)
- **GitHub Pages** (Hosting)

---

## 🚀 Cara Menjalankan Secara Lokal

Karena ini adalah website statis, Anda tidak memerlukan server backend (seperti PHP atau Node.js).

1. **Clone repositori:**

   ```bash
   git clone https://github.com/Azzlanshah/toko-cincin.git
   ```

2. **Buka folder proyek.**

3. **Jalankan:** Cukup klik dua kali (double-click) pada file `index.html` untuk membukanya di browser, atau gunakan ekstensi **Live Server** di VS Code.
